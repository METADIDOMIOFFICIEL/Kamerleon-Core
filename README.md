✨ Fonctionnalités principales

🌍 Traduction instantanée des mots-clés
Passez du français à l’anglais, de Python à Lua ou JavaScript en un clic.
Apprenez à coder dans votre langue ou explorez de nouveaux langages sans barrière.

🎨 Personnalisation totale
Adaptez les mots-clés, changez la syntaxe, créez un environnement à votre image.

⚙️ Exécution directe du code (hors ligne)
Testez vos scripts en JavaScript, Python (Pyodide) ou Lua (Fengari) — sans rien installer.

🖥️ Interface moderne et intuitive
Coloration syntaxique, minimap, sidebar interactive, thèmes variés, drag & drop.

🚫 Gestion intelligente des erreurs
Les messages d’erreur sont traduits et expliqués pour faciliter l’apprentissage.

📁 Import / export simplifié
Sauvegardez, partagez ou restaurez vos mots-clés et configurations en un clic.

🔒 Sécurité renforcée
Accès par clé d’activation pour protéger votre environnement et vos projets.

💬 Rejoignez la communauté

Partagez vos configs, proposez vos améliorations et contribuez au projet !
💡 Chaque idée compte — Kamerléon évolue avec vous.

Kamerléon — Le code qui parle votre langue.

## ⚡ Installation

## Prérequis

### Logiciels nécessaires
- [Node.js](https://nodejs.org/) (v24+),
- [Git]( https://git-scm.com/downloads/win/),
- [Vs code]( https://code.visualstudio.com/download/) ou autre editeur de code,
- [CP G1](https://github.com/METADIDOMIOFFICIEL/Metadidomi_Crone/releases/download/CPG1/Code.Protect.Ghost.1.Setup.1.0.1.exe/) ( Nécessaire pour rendre les codes ghost visible avec MODE DE PASSE:Kamerleon-181025. Voici comment l'utiliser [![
Le logiciel qui crée ce que L'IA ne comprend pas encore (les fichiers Ghost)](https://img.youtube.com/vi/E98KvFh7-yo/hqdefault.jpg)](https://youtu.be/E98KvFh7-yo?si=L9Afp6s1TW1SMc36)

  ## Important: Vous pouvez supprimer l'extension *.ghost* une fois que vous le code est visible grâce au mot de passe, si vous utiliser [Vs code]( https://code.visualstudio.com/download/) démarrer le en mode admin.

Clonez ce repo et lancez l’application  ou copiler avec run build:

```bash
git clone https://github.com/METADIDOMIOFFICIEL/Kamerleon-Core.git
npm install <-- Permet d'installer tous les dépendances le processus est un peu long, prévoir 500Mo mini pour chaque téléchargement complet -->
npm start <-- Pour tester -->
npm run build <-- Pour compiler en .exe  -->
